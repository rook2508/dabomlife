A FEW THINGS TO KNOW

체험 전에,
궁금할 수 있는 것들.

지금 어떤 기능을 체험할 수 있나요?+

한국어 음성·텍스트 입력, 생활 요청의 규칙 기반 분류, 단계별 안내, 본인·보호자 확인 시뮬레이션, 최근 내역 저장, 큰 글씨와 모바일 화면을 체험할 수 있습니다.

실제 주문이나 예약까지 처리하나요?+

현재 MVP는 준비와 확인 흐름을 검증하는 데모입니다. 실제 상품·병원 조회, 주문·결제, 예약 확정, 본인인증 및 민원 제출은 실행하지 않습니다.

Claude는 어떻게 활용할 계획인가요?+

현재 체험은 정해진 키워드와 안내 문구로 작동합니다. Claude API를 이용한 자연어 의도 파악과 후속 질문은 가능한 확장 방향이며, 구현 여부는 아직 정해지지 않았습니다.

보호자에게 알림이 실제로 전송되나요?+

현재는 같은 브라우저 화면에서 승인 요청·승인·거절 역할을 체험합니다. 원격 보호자 계정과 실제 알림 전송은 검토 가능한 확장 방향입니다.

입력한 내용과 음성은 어떻게 처리되나요?+

데모 내역은 해당 브라우저의 로컬 저장소에 저장되며 내역 지우기로 삭제할 수 있습니다. 실제 개인정보 대신 예시를 사용해주세요. 음성 입력은 지원 브라우저의 음성 인식 기능을 사용하고, 해당 제공업체의 처리 정책을 따릅니다.

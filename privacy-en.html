Demo privacy information

This explains the information processed by the current Dabom browser demo. It describes how information is handled in the interactive demo.

Information updated: October 8, 2026

1. Demo inputs and local storage

Requests, approval state and recent history are stored in your browser’s localStorage. The demo does not have a separate Dabom account or backend receiving these inputs. Please use the provided sample requests, rather than personal or sensitive information.

2. Deleting local information

The Clear history control removes recent history. You can remove all local state using your browser’s site-data controls. Pending approval state is stored separately, so finish the approval/rejection flow or clear all site data to remove it.

3. Voice input

Voice input uses the Web Speech API in supported browsers. Processing may take place outside your device, according to the browser provider’s service and policies. The microphone requires an explicit browser permission after you choose the voice control. Text and example buttons can be used instead.

4. Hosting and external resources

This site is hosted on Sites, and private access may require the hosting provider’s sign-in. Fonts are loaded from Google Fonts; routine connection information may be sent to that provider. We have not added separate visitor analytics, advertising trackers or newsletter collection.

5. Features not included

The demo does not call the Claude API, send remote caregiver notifications, take payments, order goods, book appointments or submit public documents. People shown in the site imagery are AI-generated illustrative brand scenes, not real customers or case studies.

6. Future changes

Before adding accounts, API calls, remote approval or service integrations, we will define the information-processing scope and necessary consent flows, then update this notice.

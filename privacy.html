데모 개인정보 안내

다봄의 생활비서 체험에서 어떤 정보가 처리되는지 설명합니다. 이 안내는 웹사이트의 인터랙티브 데모에서 처리되는 정보에 적용됩니다.

안내 기준일: 2026년 10월 8일

1. 데모 입력과 로컬 저장

데모는 입력한 요청, 승인 상태 및 최근 내역을 사용자의 브라우저 로컬 저장소(localStorage)에 보관합니다. 다봄의 별도 계정이나 서버로 전송하는 기능은 현재 구현되어 있지 않습니다. 개인 식별 정보나 민감한 정보 대신 제공된 예시 문장을 사용해주세요.

2. 내역 삭제

데모 화면의 “내역 지우기”로 최근 내역을 삭제할 수 있습니다. 브라우저의 사이트 데이터 삭제 기능으로 해당 사이트의 로컬 저장소 전체를 지울 수도 있습니다. 현재 대기 중인 승인 요청은 최근 내역과 별도로 저장되므로, 승인·거절을 마치거나 사이트 데이터를 삭제해주세요.

3. 음성 입력

음성 입력은 Web Speech API를 지원하는 브라우저에서만 작동합니다. 음성 처리는 브라우저 제공업체의 서비스와 정책에 따라 기기 밖에서 이루어질 수 있습니다. 마이크는 사용자가 음성 입력 버튼을 누른 후 브라우저 권한을 허용해야 사용할 수 있습니다. 직접 입력과 예시 버튼으로도 모든 데모 흐름을 체험할 수 있습니다.

4. 호스팅과 외부 리소스

사이트는 Sites에 호스팅되며 비공개 접근 시 호스팅 제공업체의 로그인이 필요할 수 있습니다. 글꼴은 Google Fonts에서 제공되며, 해당 리소스를 불러오는 과정에서 제공업체에 통상적인 접속 정보가 전달될 수 있습니다. 별도의 방문 분석, 광고 추적, 뉴스레터 수집 기능은 추가하지 않았습니다.

5. 현재 제공하지 않는 기능

Claude API 호출, 원격 보호자 알림, 결제, 주문, 실제 예약, 민원 제출 및 개인정보를 외부 서비스에 자동 전송하는 기능은 현재 데모에 포함되지 않습니다. 사이트의 인물 이미지는 AI로 제작한 브랜드 콘셉트 이미지로, 실제 고객이나 사용 사례를 의미하지 않습니다.

6. 안내의 변경

실제 계정, API, 원격 승인 또는 서비스 연동을 추가할 때에는 정보 처리 범위와 필요한 동의 절차를 정리하고 이 안내를 업데이트할 예정입니다.
